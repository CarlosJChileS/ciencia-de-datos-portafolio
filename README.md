# Ciencia de datos — portafolio y aprendizaje

Repositorio personal para documentar mi progreso en ciencia de datos, analítica y visualización.

## Áreas del portafolio

### 1. Análisis de datos

Trabajo con datos para responder preguntas, encontrar patrones y apoyar decisiones.

- Análisis exploratorio.
- Limpieza y transformación.
- Indicadores y análisis de negocio.
- Proyectos de ventas, finanzas y productos.

Material relacionado: `01_portafolio/` y `02_analitica_de_datos/`.

### 2. Ciencia de datos

Ruta de crecimiento hacia un flujo completo de datos: adquirir, limpiar, analizar, modelar y comunicar resultados.

- Python para datos.
- SQL y bases de datos.
- Estadística.
- Machine learning.
- Automatización y reproducibilidad.

Esta área se irá ampliando con nuevos notebooks y proyectos.

### 3. Visualización de datos y Business Intelligence

Creación de dashboards y reportes interactivos para comunicar hallazgos.

- Power BI.
- Excel avanzado.
- Power Query y procesos ETL.
- DAX, métricas y modelado dimensional.
- Diseño de dashboards orientados a decisiones.

Material relacionado: `03_formacion_excel/` y `04_power_bi/`.

### 4. Minería de datos

Exploración de técnicas para descubrir relaciones, segmentos, tendencias y predicciones en los datos.

- Segmentación.
- Clasificación.
- Análisis de patrones.
- Preparación de datos para modelos.

El portafolio ya incluye material y prácticas identificadas como proyectos de minería; esta sección crecerá con implementaciones documentadas.

## Organización de archivos

- `01_portafolio/`: proyectos propios de Excel y Power BI.
- `02_analitica_de_datos/`: prácticas académicas de analítica, ETL y dashboards.
- `03_formacion_excel/`: ejercicios de Excel, Power Query, DAX y modelado.
- `04_power_bi/`: prácticas y reportes de Power BI.

## Objetivos

- Consolidar fundamentos de Excel, Power Query y DAX.
- Construir dashboards claros y orientados a decisiones.
- Documentar cada proyecto: pregunta, datos, transformación, análisis y conclusiones.
- Ampliar el portafolio hacia Python, SQL, estadística y proyectos relacionados con minería.
