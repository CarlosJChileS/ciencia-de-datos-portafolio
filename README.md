# Ciencia de datos — portafolio y aprendizaje

Repositorio personal para documentar mi progreso en ciencia de datos, analítica y visualización.

## Contenido

- `01_portafolio/`: proyectos propios de Excel y Power BI.
- `02_analitica_de_datos/`: prácticas académicas de analítica, ETL y dashboards.
- `03_formacion_excel/`: ejercicios de Excel, Power Query, DAX y modelado.
- `04_power_bi/`: prácticas y reportes de Power BI.

## Objetivos

- Consolidar fundamentos de Excel, Power Query y DAX.
- Construir dashboards claros y orientados a decisiones.
- Documentar cada proyecto: pregunta, datos, transformación, análisis y conclusiones.
- Ampliar el portafolio hacia Python, SQL, estadística y proyectos relacionados con minería.
